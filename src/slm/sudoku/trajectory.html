Info and mean scores 

      

      

        Per-seed scores
        

      

      

        Colors are arithmetic mean probabilities across all seeds, including
        mask-forced zeros. Counts are mean candidate counts. The candidate board
        shows digits present in any seed, with exact survival counts
        underneath (surviving seeds / total seeds). It is not one sampled board.
        Cell borders: amber = reference present in some seeds, red = absent,
        blue = selected. Selected status cells have alternating
        blue/status-color segments. Bold digits mark the reference; there are no
        green borders. No majority-vote solution is used to calculate scores. A
        bold overview border means every seed is a singleton; a bold expanded
        border means that digit survives in every seed.

Whole-board candidates through time

        
        
        

        
        

        

          Each cell shows all candidates at the selected state; the sets shrink
          and singletons become large digits. n = candidate count, −/+ =
          removed/added counts. Cell positions stay fixed. Colors still use
          probabilities before the selected transition. Cell borders: red
          = reference lost, blue = selected. A selected error cell has
          alternating red/blue segments. Bold digit = reference; gold = final
          decoded digit. Purple cells share the selected cell's row, column or
          box (structural peers, not all attention connections).
